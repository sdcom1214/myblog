# 원본 플레이 분석

대상: https://slbcareer.com/ · 확인일: 2026-10-09. 클라우드 Chromium에서 실제 화면과 버튼을 조작했습니다. 원본의 핵심 경로를 신규 선수부터 대학, 첫 계약, 프로 시즌, 훈련, 은퇴까지 확인했습니다. 로그인이나 실제 사용자 계정, 공개 랭킹 등록은 수행하지 않았습니다.

| 관찰한 단계 | 원본 동작 | 축구 버전 |
| --- | --- | --- |
| 홈 | 경기장 일러스트, 큰 로고, 새 인생, 1:1/친구/팀, 하단 5개 메뉴 | 축구 경기장·축구 로고와 동일한 탐색 구조 |
| 선수 생성 | 이름, 번호, 손, 투수/타자, 희망 구단, 출신 고교 | 이름, 번호, 발, FW/MF/DF/GK, 리그·실제 구단·아카데미 |
| 후보 3명 | 카드 공개 후 능력치 비교, 모두 시작 합계 50 | 후보 3개, 동일 합계 50, 포지션별 능력치 |
| 성장 방향 | 역할과 최대 2개 집중 육성 | 축구 역할, 최대 2개 성장 비중 선택 |
| 첫 시즌 | 고교 기록, 전국대회, 성장, 팬 피드 | U18 기록, 국가별 유소년 대회, 성장, 팬 피드 |
| 진로 | 프로 드래프트 또는 대학, 2년 단위 평가 | 프로 테스트 또는 U21·U23, 2시즌 단위 평가 |
| 계약 | 구단 제안과 이름 서명 | 실제 유럽 구단 제안과 이름 서명 |
| 특별훈련 | 5회 타이밍 시도, 회당 0/1/2점, 점수 × 0.4 보너스 | 같은 조작 구조, 축구 능력치 훈련 |
| 프로 | 2군 성장, 1군 기록, 순위와 연혁 | 육성팀·1군 구분, 축구 기록, 소속 리그 순위 |
| 은퇴 | 확인, 누적 기록과 Legacy Score 카드 | 축구 경력 점수, 카드 내보내기, 새 인생 |

원본 훈련은 커리어 전체 3회, 시즌당 1회, 능력치별 1회 제한을 표시했습니다. 실제로 5회 시도와 보너스 반영을 확인했습니다. 축구 버전에도 이 제한을 적용하고 진행 중인 시도를 자동 저장합니다.

원본의 세로 프레임, 큰 행동 버튼, 모서리가 둥근 통계 카드, 헤더 OVR, 시즌/커리어/선수/우승 연혁 탭을 유지했습니다. 대학과 국내 가상 구단은 사용자의 추가 요청에 따라 유럽 아카데미·U21/U23·실제 구단으로 전환했습니다. 축구 경기 결과와 성장 계산식은 독립 구현입니다.

온라인 매치, 계정 기반 복구, 공개 랭킹은 로그인 없이 검증할 수 없었습니다. 원본의 로그인 후 동작과 직접 동일하다고 주장하지 않습니다. 축구 버전은 이후 SQLite 서버 기반 계정·친구 매치·팀 배틀·공유 랭킹을 구현했으며, 별도 두 계정으로 검증했습니다. 최신 범위는 [서버 기능 문서](online-server.md)와 [수정 보고서](audit/fixes.md)를 참고하세요.

## 적용한 UX 개선

집중 육성의 최대 2개와 배분 의미를 선택 전에 표시합니다. 프로 제안은 계약서 확인과 서명 후 확정됩니다. 저장 파일 가져오기 전 기존 기록을 내보냅니다. 열린 모달은 키보드 포커스를 유지하고 Escape로 닫을 수 있습니다. 훈련은 터치와 Space/Enter를 지원하며 새로고침 이후 시도 수가 복구됩니다.
