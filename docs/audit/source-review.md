# 추가 소스 검토 — 2026-10-12

검토 대상은 클라이언트와 Node/SQLite 서버 소스입니다. 실제 서비스 계정이나 운영 서버에 대한 침투 테스트를 수행한 결과는 아닙니다. 이전 [보안 검토](security/review.md)와 [브라우저 호환성 검토](instagram/review.md)에 이어 발견한 경로를 수정했습니다.

## 보안 수정

- **Google 계정 자동 연결:** 이메일/비밀번호 가입은 이메일 소유권을 인증하지 않습니다. 이전에는 Google의 인증된 이메일과 기존 가입 이메일이 같으면 두 인증 수단을 같은 계정에 연결했습니다. 이제 Google의 고유 `sub`로 계정을 찾고, 새로운 Google 계정과 기존 이메일 계정이 충돌하면 409를 반환합니다. 이미 연결된 Google 계정은 이메일이 바뀌어도 같은 `sub`의 계정으로 로그인합니다. 계정 연결은 별도 인증된 연결 흐름을 구현하기 전까지 제공하지 않습니다.
- **정적 파일 경계:** 숨김 파일, NUL 경로, 공개 디렉터리 밖으로 향하는 심볼릭 링크를 차단합니다. 실제 파일 경로를 확인한 뒤 읽고, 비동기 파일 오류도 공통 오류 처리에서 받습니다. 500 응답에는 내부 예외 내용을 노출하지 않습니다.
- **엔딩 데이터:** 새 UI는 이름·구단·수상 문구를 HTML 이스케이프하고, 기존 CSP를 유지합니다. 화면 재생 체크포인트는 서버 커리어·온라인 점수에 포함하지 않습니다. 이미지 저장은 기존 PNG 경로를 사용하며 JSON 백업은 별도로 유지합니다.

## 최적화

- SQL 준비문을 재사용하고 커리어·대전·세션 조회 인덱스를 추가했습니다.
- 변경 없는 보관 선수는 다시 쓰지 않아 갱신 시각도 유지됩니다. 수정된 수입 기록의 검증 상태는 계속 해제됩니다.
- 시즌마다 불필요하게 지갑/장비를 조회하지 않고, 검증 비교에서 반복 JSON 변환을 제거했습니다.
- 정적 파일을 비동기로 읽고, 은퇴 타임라인은 추가된 시즌 행만 삽입합니다. 배경 PNG 두 개는 WebP로 압축했습니다.

전체 처리량 개선율을 측정한 벤치마크는 수행하지 않았습니다. 보관 선수 재저장 회귀 테스트에서는 진행 명령의 쓰기가 현재 선수와 저장 스냅샷 두 건으로 유지되는 것을 확인했습니다.

## 검증

- `npm test`: 66개 통과. 추가 서버 회귀 4개는 이메일 충돌, Google 고유 ID와 콜백 재사용, 숨김 파일/외부 링크, 보관 선수 쓰기와 검증 해제를 확인합니다.
- 빌드 성공. 브라우저 온라인 11개, 일반 화면 14개, 보안 3개 시나리오, 마우스/터치 사인·PNG 저장 2개 시나리오 통과.
- 네 포지션과 온라인 두 선수의 여섯 커리어를 자연 은퇴까지 완료했습니다. 새 은퇴 연출은 비회원 공격수와 온라인 골키퍼로 별도 검증했습니다. [엔딩 검증 자료](../retirement/review.md).
- Google 회귀는 OAuth 응답을 고정한 서버 테스트입니다. 실제 Google 계정 로그인 및 Instagram/iOS 실기기 검증은 포함하지 않습니다.
