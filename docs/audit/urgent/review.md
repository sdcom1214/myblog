# 카드 이미지 저장·계약 사인 긴급 수정

2026-10-11 검증. 카드 저장 버튼이 JSON 저장 데이터를 Blob으로 내려보냈습니다. 다운로드를 지원하지 않는 내장 브라우저가 이 Blob을 페이지로 열면 저장 데이터가 표시되고, 문자 인코딩도 잘못 해석될 수 있었습니다.

카드 저장은 이제 한글 글꼴과 구단 로고를 포함한 780×1180 PNG를 생성합니다. 미리보기에서 PNG 다운로드 또는 지원되는 브라우저의 파일 공유를 선택하고, 내장 브라우저에서는 미리보기 이미지를 길게 눌러 저장할 수 있습니다. JSON은 명확하게 구분한 ‘커리어 데이터 백업 (JSON)’에만 남겼으며 UTF-8을 지정했습니다. 이 화면에 서버 비밀정보나 소스 코드를 제공하는 기능은 없습니다.

계약서의 기존 사인 영역은 입력을 받지 않는 일반 텍스트 상자였습니다. 마우스·손가락·펜으로 직접 그릴 수 있는 사인 영역을 추가하고, 이름 사인과 지우기를 유지했습니다. 유효한 사인이 있을 때만 계약 확정 버튼을 활성화합니다. 새 계약과 FA 계약에 모두 적용됩니다.

검증: `npm test` 34개, 비회원 Chromium 14개 및 `node tests/browser-server.mjs tests/browser-urgent.py` 성공. 실제 마우스 비회원과 터치 온라인 계정에서 사인·계약 체결·PNG 다운로드·별도 JSON 백업을 확인했습니다. PNG 파일 시그니처와 확장자를 검사했으며, 페이지 URL이 바뀌거나 JSON이 화면에 표시되지 않았습니다. 인스타그램 앱 자체와 iOS 실기기는 이 환경에서 실행하지 않았습니다.
