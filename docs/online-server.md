# 온라인 서버와 1:1 구현 범위

Node.js 24 내장 SQLite와 HTTP 서버를 사용합니다. `npm run dev`는 API(4174)와 Vite(4173)를 함께 시작합니다. 서버 데이터는 `.local/server.sqlite`에 저장하며 Git에 포함되지 않습니다. 클라우드 실행 환경에서는 지속되지만 별도 배포의 재시작·교체에 대비하려면 `FOOTBALL_DB`를 영구 볼륨 경로로 지정해야 합니다.

## 구현한 기능

- 이메일 가입·로그인·로그아웃, 비밀번호 scrypt 해시, HttpOnly 세션 쿠키. 별도 기기·브라우저에서 같은 계정으로 저장을 복구합니다.
- 서버가 생성·성장·시즌·계약·이적·훈련·은퇴를 계산하는 온라인 커리어. 수정·가져온 기록은 공유 랭킹과 온라인 팀 편성에서 제외합니다. 저장 버전 충돌은 409로 처리하며 오래된 기기에서 새 기록을 덮어쓰지 않습니다.
- 닉네임 검색, 친구 초대·수락·거절·취소, 포지션별 랜덤 매칭. 같은 초기 후보로 각각 새 커리어를 진행하며, 두 선수가 은퇴하면 서버가 LEGACY SCORE를 비교합니다. 대전 진행 상태는 4초마다 갱신합니다.
- 라이브 랭킹, 신인 후보, 팀 ELO, 서버 최초 업적, 계정별 개인 업적. 공개 응답에는 이메일·비밀번호·세션을 포함하지 않습니다.
- 은퇴 선수 MY CLUB 보관(기본 20칸), 목록·카드 보기, 포지션·기록 정렬, 시즌/레거시 구분, 보관 해제. 본인의 온라인 보관 선수로 최대 11인 팀을 편성합니다.
- 도장깨기와 다른 계정의 팀을 상대하는 랭킹전, 서버 경기 결과·대칭 ELO·전적 저장.
- 선수 슬롯 +12(100 FC), 팀 슬롯 +1(60 FC), 세트(140 FC), 회귀권(5 FC), 개명권(10 FC), 사용 내역. 출석 20 FC와 온라인 시즌 5 FC로 충전합니다. 회귀는 같은 초기 후보를 재사용하는 새 U18 커리어이며 1회 제한을 검증합니다.

## 외부 연결과 차이

Google OAuth 코드는 연결되어 있지만 현재 세 가지 설정이 없어 실제 Google 로그인은 검증하지 못했습니다. `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `GOOGLE_REDIRECT_URI`를 환경 설정에 등록하고 Google OAuth 콘솔의 허용 리디렉션 URI를 일치시켜야 합니다. 콜백 경로는 `/api/auth/google/callback`입니다. 비밀값을 채팅·Git에 저장하지 마세요. `.env.example`은 변수 이름의 참고 자료이며 실제 실행에는 환경 변수를 주입합니다. HTTPS 배포에서는 `COOKIE_SECURE=true`를 지정합니다.

원본의 실제 사인볼 현금 결제는 복제하지 않았습니다. 현재 상점은 게임 보상 FC를 사용합니다. 실제 결제까지 운영하려면 결제 사업자·상품·결제 승인 및 웹훅 구성을 별도로 연결해야 합니다.

원본의 모든 계산식을 그대로 사용하는 프로젝트는 아닙니다. 축구 통계·대회·입단/이적/은퇴 규칙은 독립적으로 구현했습니다. 야구의 병역·MLB·투구폼·숨겨진 능력/커리어 분기 전체에 대응하는 축구 시스템은 아직 없습니다. 생성 아트의 로고·경기장과 일부 선수/은퇴 카드 상세도 원본과 차이가 남습니다. 원본의 로그인 후 전용 화면은 계정 접근 없이 완전 비교할 수 없으므로, 이 결과를 완전한 1:1 복제라고 표시하지 않습니다.

## 검증

`npm test`: 엔진 26개 + 서버 14개. `python tests/browser-smoke.py`: 비회원 14개 검증. `npm run build` 후 `node tests/browser-server.mjs`: 임시 메모리 DB와 빌드된 실제 HTTP 서버에 두 브라우저 계정으로 온라인 11개 검증을 수행합니다. 개발 DB에 테스트 계정을 남기지 않습니다.

`node tests/browser-server.mjs tests/browser-career-full.py`는 네 포지션과 온라인 두 선수의 여섯 커리어를 화면 조작으로 자연 은퇴까지 진행합니다. 수동 은퇴나 저장 데이터 수정 없이 최종 시즌 기록·은퇴 사유·새로고침 복구·내보내기·동일 후보와 대전 점수·승패를 확인합니다. 원본 플레이 관찰과 수정 근거는 [완주 검수](playthrough/review.md)에 있습니다.

`node tests/browser-server.mjs tests/browser-training.py`는 10개 능력치에 연결된 9종 게임을 실제 화면 조작으로 각 5회 완료하고 점수·능력 상승·진행 복구·수상/업적 화면을 확인합니다. `node tests/browser-server.mjs tests/browser-urgent.py`는 마우스 비회원·터치 온라인 계정의 사인과 PNG 저장을 확인합니다. 카드 이미지와 JSON 백업은 분리되어 있습니다.
