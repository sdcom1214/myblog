# 유럽 축구 참고 데이터

데이터는 `src/data.js`에 모았습니다. 2025/26 구단 구성을 고정 목록으로 사용하고, 게임은 2026/27부터 가상의 시즌을 생성합니다. 팀 전력 수치는 게임 밸런스 값입니다. 실제 순위, 승격·강등, 이적, 급여, 경기 기록을 예측하거나 가져오지 않습니다.

이 표는 **아카데미 배경**을 연결합니다. 현재 소속 구단 목록이 아닙니다. 아카데미의 시설명은 현재 널리 쓰이는 대표 명칭으로 표기하므로, 참고 선수가 역사적으로 해당 시설에서 훈련했다는 뜻은 아닙니다. 특히 콜 파머는 맨시티 아카데미 배경으로 분류합니다. 페드리를 라마시아, 주드 벨링엄을 레알 유소년 출신으로 분류하지 않습니다.

참고 이름을 선택하면 이름·포지션·주발·참고 등번호를 입력합니다. 이후의 능력치와 나이, 성적, 구단 제안은 게임이 생성합니다. 직접 이름을 수정할 수도 있습니다.

## 성장 경로

원본의 고교 → 대학 2년/추가 2년 → 프로 경로를 U18 → U21 육성 2시즌 → U23 리저브 추가 2시즌으로 바꿨습니다. 각 국가가 서로 다른 유소년·리저브 규칙을 사용하는 점을 감안해, 성장 선택은 공통 게임 경로로 단순화했습니다. U18 대회 이름은 국가에 따라 다르게 표시하고, 국제 유소년 초청컵은 게임 안의 가상 대회입니다. 참가 자격·경기 일정·실제 컵 대진까지 복제하지 않습니다.

## 참고 링크와 확인 범위

2026-10-09에 다음 공식 페이지를 클라우드에서 확인했습니다.

- [Premier League 구단](https://www.premierleague.com/en/clubs): HTTP 200. 실제 구단 명칭 참고.
- [LALIGA 구단](https://www.laliga.com/en-GB/laliga-easports/clubs): HTTP 200. 페이지는 현재 시즌을 표시하므로 게임의 고정 기준 시즌과 구분합니다.
- [FC Barcelona · La Masia](https://www.fcbarcelona.com/en/club/facilities/la-masia): HTTP 200. 아카데미 명칭 참고.
- [Ajax youth academy](https://english.ajax.nl/club/youth-academy/): HTTP 200. 아카데미 배경 참고.

아스널 아카데미 페이지는 403, 시티·바이에른·스포르팅의 시도한 시설 페이지 경로는 404로 응답했습니다. 이 페이지들을 이번 조사에서 열람한 근거로 간주하지 않았습니다. 전체 목록은 널리 알려진 구단·아카데미 배경을 바탕으로 정리했으며, 실시간으로 검증된 선수 명단이라고 표시하지 않습니다.
